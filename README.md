## 🚀 Featured Projects

### 🔥 Forge • AI Developer Workspace

An AI powered developer workspace built using **MERN, Redis, Qdrant, Docker, and Google Gemini** that enables project aware conversations through Retrieval Augmented Generation (RAG). Implements hybrid retrieval using Reciprocal Rank Fusion (RRF) with asynchronous indexing powered by BullMQ and Redis.

### 🛰️ InfraGhost AI

An AI powered infrastructure verification platform using **Gemini Vision** to analyze geotagged infrastructure reports and compute automated Ghost Scores for asset authenticity. Includes Mapbox analytics, MongoDB integration, and secure backend architecture.

### 🌿 Plant Leaf Disease Detection & Treatment

A real time plant disease detection system using a custom trained **YOLOv11** model integrated with **Google Gemini** for intelligent treatment recommendations. Built with Flask for fast inference and annotated predictions.

### 🏠 Wanderlust

A full stack Airbnb clone built with the **MERN** stack featuring authentication, property listings, Cloudinary image uploads, Mapbox integration, and a responsive interface.

### 🎵 Emotion Based Song Recommendation Chatbot

An NLP powered chatbot that analyzes user sentiment and recommends personalized music based on emotional context.
